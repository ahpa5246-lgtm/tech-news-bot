# Tech News Collector

مكوّن أولي لجمع أخبار التقنية والبرمجيات والبرمجة من مصادر RSS/Atom موثوقة، ثم تنظيفها وتصنيفها وتخزينها محليًا في SQLite. يحافظ المشروع على العنوان والوصف والرابط والتاريخ واللغة الأصلية حتى يمكن تمرير المادة لاحقًا إلى مرحلة كتابة عربية طبيعية.

> لا ينشر هذا الإصدار أي شيء إلى Telegram، ولا يستخدم واجهة ذكاء اصطناعي لإعادة الصياغة أو الترجمة.

## المتطلبات

يحتاج المشروع إلى **Python 3.12 أو أحدث** واتصال بالإنترنت عند تشغيل الجامع. المكتبة الخارجية الوحيدة اللازمة لجلب RSS هي `feedparser`، وتوجد أيضًا `python-dotenv` ضمن المتطلبات تمهيدًا لقراءة ملف البيئة في المراحل التالية.

## التثبيت

من داخل مجلد المشروع:

```bash
python -m venv .venv
```

على Linux وmacOS:

```bash
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
```

على Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

لا تضع أسرارًا أو رموز وصول في المستودع. ملف `.env` مستثنى من Git، و`.env.example` يحتوي على قيم توضيحية فقط.

## التشغيل

بعد تفعيل البيئة الافتراضية شغّل:

```bash
python main.py
```

ينشئ البرنامج قاعدة البيانات تلقائيًا في `data/news.db`، ثم يفحص المصادر، يستبعد الأخبار الأقدم من 48 ساعة، ويطبع تقريرًا موجزًا بالعناصر الجديدة المخزنة.

## بنية الملفات

| الملف | الوظيفة |

| `models.py` | هياكل البيانات typed الخاصة بالمقالات ونتائج المصادر. |

## إعداد المصادر

توجد المصادر الفعالة في القاموس `RSS_FEEDS` داخل `config.py`. لإضافة مصدر، أضف زوجًا من الشكل التالي:

```python
RSS_FEEDS["اسم المصدر"] = "https://example.com/feed.xml"
```

يجب استخدام رابط RSS أو Atom مباشر، وليس صفحة HTML عادية. إذا تعطل مصدر، يسجل البرنامج تحذيرًا ويكمل معالجة بقية المصادر دون توقف شامل.

المصادر المبدئية الفعالة هي OpenAI، Google DeepMind، GitHub، Hugging Face، NVIDIA، Microsoft، Apple، TechCrunch، The Verge، Ars Technica، وHacker News. تتغير بنية المواقع بمرور الوقت، ولذلك يتحقق البرنامج من الاستجابة أثناء التشغيل بدل افتراض نجاح كل رابط. تم إبقاء Anthropic معطلًا لعدم توفر رابط RSS رسمي مستقر تم التحقق منه، كما عُطّل Meta AI لأن الرابط المختبر أعاد HTTP 404.

## كيف تعمل المرشحات؟

لا يُرفض الخبر لمجرد أن لغته الإنجليزية. يكتشف `detect_language` وجود مؤشرات عربية أو لاتينية ويخزن القيمة `ar` أو `en` أو `unknown`، مع ترك الترجمة والكتابة العربية لمرحلة لاحقة.

يستخدم مرشح الصلة مجموعة كلمات تقنية في العنوان والوصف، مثل الذكاء الاصطناعي والبرمجة والأمن السيبراني والعتاد والسحابة وقواعد البيانات. كما يستبعد المحتوى العام غير التقني عندما تظهر مؤشرات مثل الرياضة أو أخبار المشاهير دون إشارة تقنية ذات معنى.

يطبق مرشح السلامة ثلاث حالات. فالمحتوى الذي يتضمن ترويجًا مباشرًا لمواد إباحية أو كراهية أو تجنيد إرهابي أو مخدرات غير قانونية أو عنف صادم يُوسم `REJECTED`. أما إذا ظهر مصطلح حساس ضمن سياق بحث أو تقرير أو تحليل أو سلامة، فيُوسم `REVIEW` بدل الحذف التلقائي. هذا تصميم محافظ، لكنه يظل مرشحًا حتميًا بسيطًا وليس بديلًا عن المراجعة البشرية.

درجة الأهمية من 0 إلى 5، وتُرفع عند وجود إشارات تقنية وأفعال مثل إطلاق أو إصدار أو ثغرة أو بحث أو تحديث. لا تُخزن افتراضيًا إلا العناصر التي تبلغ `MIN_IMPORTANCE_SCORE`، وقيمته الافتراضية 3.

## كشف التكرار

يستخدم النظام عدة إشارات متدرجة: إزالة شظايا URL، مطابقة الرابط، و`content_hash` مبني على العنوان والرابط وتاريخ النشر. كما يقارن العناوين الحديثة باستخدام `SequenceMatcher`؛ وإذا تجاوز التشابه 0.88 يعد المقال مكررًا. يحتفظ النظام بالرابط الأصلي والمصدر الأصلي لتسهيل اختيار المصدر الأكثر موثوقية لاحقًا.

## قاعدة البيانات والحالات

جدول `articles` يحوي: `id`، `source`، `title`، `url`، `published_at`، `summary`، `language`، `collected_at`، `content_hash`، `importance_score`، و`status`. الحالات المدعومة هي `NEW` و`ACCEPTED` و`REJECTED` و`REVIEW` و`PUBLISHED`، مع أن النشر غير منفذ حاليًا.

## الإعدادات

يمكن تعديل `MAX_ARTICLE_AGE_HOURS` و`REQUEST_TIMEOUT_SECONDS` و`MIN_IMPORTANCE_SCORE` و`NEWS_DATABASE_PATH` في `.env`. في النسخة الحالية تُقرأ القيم مباشرة من البيئة عند تشغيل البرنامج.

## القيود المعروفة

بعض مواقع الأخبار قد تمنع الطلبات الآلية أو تغير رابط RSS أو تعرض ملخصًا قصيرًا فقط. لا يجلب هذا الإصدار نص المقال الكامل، ولا يتحقق من الحقائق، ولا يحدد المصدر الأكثر سلطوية بين القصص المتشابهة، ولا يستخدم نموذجًا لغويًا لفهم السياق. كما أن اكتشاف اللغة والسلامة والموضوعية قائم على قواعد وكلمات مفتاحية، لذا تُستخدم حالة `REVIEW` عند الغموض.

## ما لم يُنفذ بعد

لم تُنفذ مراحل AI Researcher أو Fact Checker أو Arabic AI Writer أو Human Review UI أو Telegram Publisher أو الجدولة التلقائية أو التصفح المستقل. هذه البنية تفصل الجامع عن تلك المراحل بحيث يمكن إضافتها لاحقًا دون إعادة كتابة طبقة RSS وقاعدة البيانات.
